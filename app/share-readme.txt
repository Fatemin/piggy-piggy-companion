🐖 piggy-piggy-companion 桌面猪猪 · 使用说明
=====================================

一只住在你桌面右下角的小猪。它会饿、会脏、会生病，
要你喂它、给它洗澡、带它打工赚钱、上学、去旅行。

--------------------------------------------
一、安装
--------------------------------------------

【苹果电脑 Mac】用 “piggy-piggy-companion-0.15.2-universal.dmg”

  1. 双击这个 .dmg 文件
  2. 在弹出的窗口里，把 “piggy-piggy-companion” 图标拖到 “Applications（应用程序）” 文件夹
  3. 打开 “应用程序”，双击 “piggy-piggy-companion”
  4. 如果弹窗说 “无法验证开发者” 或 “Apple 无法检查其是否包含恶意软件”：
       - 先点 “完成”（或 “取消”）
       - 打开 “系统设置” → “隐私与安全性”
       - 往下翻，看到 “已阻止 ‘piggy-piggy-companion’ …”，点旁边的 “仍要打开”
       - 输入电脑密码，再点一次 “打开”
     这一步只需要做一次。
  5. 第一次打开要等几秒钟，然后猪猪就会出现在屏幕右下角，
     屏幕最上方的菜单栏里也会多一个小猪图标。

【Windows 电脑】用 “piggy-piggy-companion-Setup-0.15.2.exe”

  1. 双击这个 .exe 文件
  2. 如果出现蓝色窗口 “Windows 已保护你的电脑”：
       点 “更多信息” → 再点 “仍要运行”
  3. 它会自己装好并打开，桌面上也会有 “piggy-piggy-companion” 快捷方式
  4. 猪猪出现在屏幕右下角；屏幕右下角的任务栏托盘里也有小猪图标
     （看不到的话，点任务栏上的 “^” 小箭头展开）

  ※ 这两个弹窗是因为这个小程序没有花钱买开发者签名，并不是病毒。

--------------------------------------------
二、怎么玩
--------------------------------------------

  ● 一开始是个纸盒 📦：戳它三下，或者右键点它再点 “拆开纸盒”
  ● 右键点猪猪：打开 / 关上菜单
       状态 · 学习 · 打工 · 商店 · 旅行 · 背包，六个图标点着玩就行
  ● 左键点猪猪：摸摸它
  ● 按住猪猪拖动：把它挪到屏幕任何地方（位置会记住）
  ● 猪猪以外的地方完全不挡鼠标，可以照常用电脑
  ● 菜单嫌小？拖菜单的左上角（或上边、左边）就能拉大，
    双击左上角恢复原来的大小
  ● 菜单右上角的 ⤢ 打开 “大面板”：左边是猪猪和状态，右边是所有操作。
    大面板有两种样子：游戏风 和 Excel 风（伪装成表格，上班摸鱼专用）。
    在大面板里连按两次 Esc（或 Ctrl+Shift+E）瞬间变成表格；
    表格最下面状态栏里的按钮可以变回来

  小贴士
  ● 喂食、洗澡、玩耍要先在 “商店” 里买东西，钱靠 “打工” 赚
  ● 猪猪靠吃东西长胖，越重个子越大：
       80 公斤变成老年猪，120 公斤长到最大（好好喂的话大概两周）
       变成老年猪以后，可以在 “状态” 页里切换 “老年猪 / 原版” 的样子
  ● 猪猪不会老死；但饿着或脏着太久会生病，生病要买对应的药
    （商店里会高亮提示），病太重也会死 —— 这时可以用 “还魂丹” 救回来
  ● 关掉电脑的时候猪猪照样在饿 —— 记得常回来看看它
  ● 起名字：在 “状态” 页点名字旁边的 ✏️。第一次免费，
    之后每次改名要一张 “更名卡”（商店 “道具”，1000 猪币）
  ● 旅行：可以去全世界 21 个地方，离你越远越贵、越久
    （每跨一个时区 +200 猪币、+1 小时）。每次都会带回纪念品，
    运气好还能带回商店买不到的当地特产。
    集齐一个地区的 6 件纪念品，猪猪会变强，还能解锁一个小技能
  ● 上学：小学 → 大学 → 研究生 → 博士。大学能同时上 2 门课，
    研究生和博士能同时上 3 门

--------------------------------------------
三、小猪图标的菜单
--------------------------------------------

  （Mac：点屏幕最上方的小猪图标；Windows：点任务栏托盘里的小猪图标）

  ● 显示 / 隐藏猪猪
  ● 猪猪回到右下角    —— 找不到猪的时候点这个
  ● 打开大面板        —— 在单独的大窗口里玩
  ● 🌐 语言            —— 中文 / 日本語 / English
                         （右键猪猪打开菜单，在 “状态” 页最下面也能切换）
  ● 开机自动启动      —— 打勾后每次开机猪猪自己出来
  ● 退出

--------------------------------------------
四、更新到新版本
--------------------------------------------

  直接安装新版就行，猪猪不会丢：
  Mac：先在小猪图标菜单里点 “退出”，再把新的 piggy-piggy-companion 拖进 “应用程序”，
       提示已存在时选 “替换”
  Windows：先在托盘小猪菜单里点 “退出”，再双击新的 Setup.exe

  旧版本叫 “DSH Piggy”：新版第一次打开时会自动把原来的猪搬过来。
  Mac 上确认猪猪都在之后，可以把 “应用程序” 里旧的 DSH Piggy 拖到废纸篓
  （旧存档 ~/Library/Application Support/DSH Piggy/ 会留着当备份）。

--------------------------------------------
五、卸载
--------------------------------------------

  Mac：先在小猪图标菜单里点 “退出”，再把 “应用程序” 里的 piggy-piggy-companion 拖到废纸篓
  Windows：“设置” → “应用” → 找到 piggy-piggy-companion → “卸载”

  猪猪的存档在：
    Mac     ~/Library/Application Support/piggy-piggy-companion/
    Windows %APPDATA%\piggy-piggy-companion\
  卸载程序不会删掉它，重新安装后还是原来那只猪。
